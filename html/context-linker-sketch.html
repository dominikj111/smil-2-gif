Why "linker", not "compiler": a real CPU needs software translated into machine code before it understands it. The LLM already understands the language — the ISA is human language. What's missing is the classic linking and loading machinery: assembly, symbol resolution, ordering, minimization — and the cache coherence that lets the assembled image stay hot at L3. The context linker is that machinery, and mwp is its project-scope prototype.
