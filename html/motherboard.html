Design choices: the CPU and RAM sit on the same row — the memory bus connects them directly (no bridge in between). The CPU drives both directions: a bidirectional two-line bus to RAM, and a bidirectional two-line routing bus down to the north bridge (routing), which mediates the drive (no south bridge). RAM holds everything currently running, stacked vertically: the linker (context assembly, a running app), the chat session, and the JigsawFlow-composed app — what the monitor shows is RAM, as in a real machine. Every bus is two lines, dots flowing one way each.
